# SACPulse — Course Submission Packages (`docs/`)

Each Semester-3 course has its own **100% self-contained submission folder** containing the complete Project Report (in **PDF** with rendered vector UML/DFD/ER diagrams, **standalone offline HTML** with pre-baked vector SVGs, and editable **Markdown** source), an **editable PowerPoint Presentation (`.pptx`)**, and a **3-Member Viva Voce & Live Demo Guide**.

> **Before Final Submission:** Replace `[Member 2 Name]`, `[Member 3 Name]`, and `[Enter Roll No]` in the cover table of the `.md` report (and Slide 1 / Team slide of the `.pptx`) if needed.
